# 验证报告

## 自动化测试

- `node --check`：扩展内容脚本、Service Worker、offscreen 页面、画廊、宣传页交互脚本均通过语法检查。
- `node tests/background.test.cjs`：6 组通过。覆盖不可信来源拒绝、支持域名校验、URL 去重与无效协议过滤、额外图片域授权、001 编号、避免重复下载、并发下载完成/中断、实际下载事件进度、服务工作线程恢复、六次会话上限和错误反馈。
- `tests/browser.html`：自包含 Chrome 浏览器用例，直接运行仓库中的提取器、真实 `fetch`、`createImageBitmap`、`OffscreenCanvas` 与 PNG Blob 转换逻辑。覆盖淘宝/天猫/京东/拼多多路径、相邻 srcset、懒加载、背景图、Shadow DOM、Logo/导航过滤、JPG/WebP/PNG、小图和损坏图、原始尺寸 PNG 签名、画廊勾选/反选/灯箱/失败重试。该页面使用 Chrome API 替身，因为扩展权限 API 只有真实 MV3 service worker 环境才可用。
- `node tests/probe-browser.cjs`：Google Chrome 155 桌面官网界面与首屏交互通过；Chrome 原生视口 1024、375、320 均无横向溢出，移动导航可打开并在跳转后关闭，所有 IntersectionObserver 内容滚动后可见，页面零运行时异常。
- `python tools/package_extension.py`：ZIP 解压校验、清单版本及核心扩展文件校验通过。发布包包含 9 个扩展运行文件和 1 份安装说明。

## 真人平台验收

尚未访问真实淘宝、天猫、京东或拼多多页面。需要在已登录的 Chrome 用户配置中分别核对商品详情识别、实际懒加载图范围、平台权限提示、单张/多张 PNG 保存，以及多文件下载提醒。部分平台有登录、外链读取限制和后台按需下载地址过期；这些情况由图片库提示原因，不应视为自动绕过。
